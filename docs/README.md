\# TrailBook



> A pleasant GPX Library for everyone.



\---



\## Overview



TrailBook は



GPXファイルを

整理・管理・閲覧するための



オフラインファーストな

GPXライブラリアプリケーションです。



GPXを独自形式へ変換せず、



ユーザーのデータを

そのまま大切に扱います。



\---



\## Features



\- GPX Library

\- Folder Management

\- Explorer-style Navigation

\- Offline First

\- Fast Search

\- Statistics

\- Replay

\- HeatMap

\- Leaflet Map

\- Long-term Maintainability



\---



\## Philosophy



TrailBook は



\- GPX First

\- Folder is Database

\- Offline First

\- Framework Free

\- Human + AI Development



を基本思想としています。
